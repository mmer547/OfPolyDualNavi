# OfPolyDualNavi

OpenFOAM（Keysight版 / openfoam.com 系列）の `polyDualMesh` を使った、MRF領域付きポリヘドラルメッシュ作成を支援するGUI（検討段階）。

**バージョン: `0.1.0.dev0`（開発中）** — 現時点では GUI はなく、検証用スクリプト（`poc/`）のみ。仕様・ファイル構成は今後変わります。

- 検証用スクリプトと実形状での試し方: [poc/README.md](poc/README.md)
